# 3U solar panel board

The solar panel is made with EnduroSAT's structure in reference, as used by STS
The solar panel consist of 7 cells connected in series and 7 bypass diodes in parallel to each one of them, and one 2input picoblade connecter on the backplane
Also mounts for CSS are added and CSS description is inside module_CSS


Solar cell :  Electronic Spices 62mm x 42mm 2V 100mAh Rectangle Shape Polycrystalline Mini Epoxy Solar Panels (Pack of 1) https://amzn.in/d/081WSEOC 

bypass diodes : SOD123 Schottky diode (nexperia CFP3)
