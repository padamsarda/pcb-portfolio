# LT8491 solar charger development board

A single-channel MPPT buck-boost charger for a 4S battery. It accepts two solar-panel inputs, with ideal diodes on the input and output.

| Setting | Value |
|---|---|
| Battery voltage | 16.0 V |
| Charge current | 1.51 A |
| Input voltage limit | 25 V |
| Switching frequency | 350 kHz |
| Interface | I2C |

Open `eval_LT8491.kicad_pro` in KiCad 10. The schematic and placement are available; signal routing is still in progress. Parts are listed in the XLSX BOM.
