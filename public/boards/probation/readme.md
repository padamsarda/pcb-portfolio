# First PCB · Team Anant probation

## System definition

- Acts as the main PCB of a simple satellite.
- Power regulation and distribution through boost and buck converters.
- 5 V and 3.3 V rails with current monitoring.
- Takes input from sensors and controls the reaction wheel.

The submitted KiCad project includes an STM32F401 microcontroller, IR2101 gate drivers, and INA226 current sensing.

Source: Team Anant probation design notes in Notion and the submitted KiCad project.
